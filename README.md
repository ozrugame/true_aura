# True Aura 0.9.0

มอดออร่าหุ้มร่างสำหรับ **Minecraft Java 1.20.1 / Forge 47.4.x** อ้างอิงบรรยากาศของ Shin ในคลิป Sancho: เปลวทองอมส้มไหลขึ้นพร้อมริ้วสว่างและพลังสีม่วงอ่อนที่เท้า

## ติดตั้งและใช้

1. ใช้ Minecraft 1.20.1 ที่ติดตั้ง Forge 47.4.x
2. ดาวน์โหลด `trueaura-0.9.0-forge-1.20.1.jar` จาก [GitHub Releases](https://github.com/ozrugame/true_aura/releases) หรือใช้ไฟล์ในโฟลเดอร์ `release` ที่ build ไว้ แล้วนำ ไปใส่ใน `mods` ของอินสแตนซ์ที่เล่น และนำไฟล์ True Aura รุ่นเก่าออกจาก `mods` ก่อน
3. เข้าโลก กด **R** เพื่อเปิดออร่า แล้วกด **F5** เพื่อดูในมุมมองบุคคลที่สาม (บาง Mac ต้องกด Fn ร่วมด้วย)
4. กด **O** เพื่อเปิดหน้าตั้งค่า หรือใช้ Mods → True Aura → Config
5. กด **R** อีกครั้งเพื่อปิด เปลี่ยนปุ่ม R/O ได้ที่ Options → Controls → Key Binds → True Aura หากชนกับมอดอื่น

ออร่าเริ่มต้นที่ปิดทุกครั้งที่เข้าโลก หลังเกิดใหม่หรือเปลี่ยนมิติ ปรับเฉพาะภาพ ไม่เปลี่ยนค่าพลังหรือดาเมจ

## นำเข้ารูปแบบออร่าของตัวเอง (0.9)

กด **O → ลักษณะ → รูปแบบ → เปิดโฟลเดอร์** แล้ววางไฟล์ JSON ใน `config/trueaura/auras/` กด **โหลดไฟล์ใหม่** เลือกชื่อรูปแบบจากรายการและกดบันทึก ตัวอย่าง 3 แบบจะสร้างให้เมื่อเปิดโฟลเดอร์ครั้งแรก ผู้เล่นอื่นที่มีมอด 0.9 เห็นแบบที่เลือกโดยไม่ต้องคัดลอกไฟล์เอง

- [คู่มือภาษาไทย: สร้างรูปทรง ชั้นพลัง และการเคลื่อนไหว](docs/custom-auras-th.md)
- [English authoring guide](docs/custom-auras-en.md)
- [ไฟล์ตัวอย่างพร้อมแก้ไข](examples/auras)

ใช้ `/aura set copy_shape Steve` เพื่อคัดลอกรูปทรงของผู้เล่นออนไลน์ หรือ `/aura player Alex set copy_shape Steve` เพื่อกำหนดให้คนอื่น (OP 2)

## เล่นหลายคน

ติดตั้ง **True Aura 0.9 บนเซิร์ฟเวอร์และเครื่องของผู้เล่นที่ต้องการเห็นออร่า** แต่ละคนเลือกค่าของตัวเองด้วย O แล้วกดบันทึก สี รูปทรง ความเข้ม และสถานะเปิด–ปิดจะส่งให้ผู้เล่นอื่นในมิติเดียวกัน ผู้ที่เข้าใหม่จะได้รับค่าปัจจุบันด้วย

หากเซิร์ฟเวอร์ไม่มีมอด หน้าตั้งค่าและออร่าของตัวเองยังใช้ได้ โดยหน้าตั้งค่าระบุว่าเห็นเฉพาะเครื่องนี้ ผู้เล่นที่ไม่มีมอดยังเข้าเซิร์ฟเวอร์ที่ติดตั้งมอดได้ แต่จะไม่เห็นเอฟเฟกต์

ค่าหน้าตาบันทึกอยู่ในเครื่องผู้เล่น แล้วส่งใหม่เมื่อเชื่อมต่อ จึงไม่ต้องคัดลอกไฟล์ตั้งค่าของผู้เล่นไปเซิร์ฟเวอร์ รองรับการวาดสูงสุด 32 ออร่าที่ใกล้ที่สุดและอยู่ในระยะ 64 บล็อก โดยลดรายละเอียดเมื่ออยู่ไกล

## คำสั่งออร่า (0.6)

ใช้ได้ในโลกเล่นคนเดียวและเซิร์ฟเวอร์ที่ติดตั้ง True Aura 0.6 กด **Tab** เพื่อเติมคำ ชื่อรูปแบบ สี เอฟเฟกต์ หรือชื่อผู้เล่น

- `/aura <คำสั่ง>` หรือ `/aura self <คำสั่ง>`: แก้ของตัวเอง ผู้เล่นทั่วไปใช้ได้ ไม่ต้องเปิด cheats
- `/aura player <ชื่อหรือ selector> <คำสั่ง>`: แก้ผู้เล่นออนไลน์ที่ระบุ ต้องมีสิทธิ์ **OP ระดับ 2** รองรับ `@a`, `@p`, `@s` และตัวกรอง selector ของ Minecraft; คอนโซล/command block ใช้รูปแบบนี้ได้ด้วย

| คำสั่งหลัง `/aura` | ผล |
| --- | --- |
| `on` / `off` / `toggle` | เปิด / ปิด / สลับออร่า พร้อมเอฟเฟกต์เมื่อสถานะเปลี่ยน |
| `status` | ดูสถานะและค่าทั้งหมด |
| `reset` | คืนค่ารูปลักษณ์และเอฟเฟกต์เริ่มต้น โดยคงสถานะเปิด–ปิด |
| `set color main gold` | สีหลัก (เลือก `highlight` สำหรับสีประกาย หรือ `base` สำหรับสีฐาน) |
| `set intensity 1.5` | ความเข้ม 0.1–เพดานคอนฟิค (เริ่มต้น 8) |
| `set size 1.2` | ขนาด 0.5–เพดานคอนฟิค (เริ่มต้น 8) |
| `set speed 2` | ความเร็ว 0.1–3 |
| `set shape lightning` | รูปทรงหนึ่งใน 10 แบบ |
| `set open_effect epicfight:ground_slam` | เอฟเฟกต์ตอนเปิด ต้องติดตั้ง Epic Fight |
| `set close_effect trueaura:none` | ไม่เล่นเอฟเฟกต์ตอนปิด |

ตัวอย่าง:

```mcfunction
/aura on
/aura set color main blue
/aura set color highlight FFFFFF
/aura set shape lotus
/aura set open_effect minecraft:dust 1 0.7 0.1 1
/aura player Steve set shape inferno
/aura player @a on
/aura player @p set close_effect trueaura:burst
/aura player Steve status
```

ชื่อสีรองรับสีของ Minecraft เช่น `gold`, `red`, `aqua`, `blue`, `white`, `dark_purple` รวมถึง `orange`, `purple`, `pink`; หรือพิมพ์ HEX 6 หลัก เช่น `FFB30F` (ถ้ามี # ให้ครอบด้วยเครื่องหมายคำพูด เช่น `"#FFB30F"`)

รูปทรง: `flame`, `flow`, `spikes`, `vortex`, `lightning`, `pulse`, `inferno`, `lotus`, `blade`, `veil`

เอฟเฟกต์ใช้ registry ID ของเกม/มอดที่เซิร์ฟเวอร์ติดตั้ง หรือ `trueaura:burst` / `trueaura:none` พารามิเตอร์ต่อท้ายเป็นแบบเดียวกับหน้าเลือกเอฟเฟกต์ ถ้าไม่ระบุจะใช้ค่าตัวอย่างของชนิดนั้น เช่น dust สีทอง, block เป็น stone และ vibration เป็น `@self` เอฟเฟกต์ที่ต้องพึ่งบริบทการต่อสู้และหน้าเลือกปิดไว้ จะใช้ผ่านคำสั่งไม่ได้เช่นกัน

ค่าเปลี่ยนทันทีและส่งให้ผู้เล่นอื่น ผู้เล่นเป้าหมายที่มีมอดจะบันทึกค่ารูปลักษณ์ลงเครื่องด้วย ถ้าเปิดหน้า O อยู่ ตัวอย่างและการแก้ที่ยังไม่บันทึกจะถูกแทนด้วยค่าจากคำสั่ง สถานะเปิด–ปิดยังรีเซ็ตตอนเข้าโลก/เกิดใหม่/เปลี่ยนมิติเหมือนเดิม และเจ้าตัวยังเปลี่ยนค่าภายหลังได้ด้วย R/O ผู้เล่นไม่มีมอดเก็บค่าเฉพาะเซสชันบนเซิร์ฟเวอร์; ผู้ชมที่มีมอดเห็นออร่านั้นได้

## ปรับหน้าตา

กด **O** เพื่อปรับผ่านหน้าตั้งค่า:

- **ลักษณะ:** ความเข้ม ขนาด ความเร็ว และรูปทรง เปลวไฟ / ไหลวน / แหลม / เกลียวพลัง / สายฟ้า / คลื่นพลัง / เปลวพุ่งสูง / กลีบพลัง / คมพลัง / ม่านพลัง
- กดปุ่ม **รูปแบบ** เพื่อเปิดรายการแบบเดิม 10 แบบและแบบนำเข้าในสองคอลัมน์ ใช้ < / > เปลี่ยนหน้า แล้วกดแบบที่ต้องการได้ทันที แบบที่ใช้อยู่มีเครื่องหมาย ✓ เลือกแล้วตัวอย่างเปลี่ยนทันที; ปุ่มกลับหรือ Esc ปิดเฉพาะรายการ
- **สี:** เลือกสีหลัก / สีประกาย / สีฐาน แล้วลากแถบรุ้งเพื่อเลือกเฉด คลิกหรือลากในแผงสีเพื่อปรับความสดและความสว่าง ไม่ต้องพิมพ์รหัสสี มีชุดสี ทอง / น้ำแข็ง / ชมพู และใช้ปุ่มลูกศรปรับสีได้
- ตัวอย่างเปลี่ยนทันทีเฉพาะเครื่องคุณ หน้าตั้งค่าจะจัดกล้องให้ตัวละครอยู่ฝั่งซ้ายพ้นแผงตั้งค่า ปรับมุมมองตามขนาดออร่า และไม่พักเกม
- **บันทึก:** จำค่าหลังปิดเกมและส่งให้เซิร์ฟเวอร์ **ยกเลิก/Esc:** ทิ้งการแก้ **รีเซ็ต:** คืนค่าเริ่มต้นในตัวอย่าง รอกดบันทึกก่อนใช้จริง

ค่าเก็บใน `config/trueaura-client.toml` ของอินสแตนซ์เดิม โดยรองรับ scale/intensity/speed จากรุ่น 0.1 ต่อได้ หากแก้ไฟล์เองแนะนำให้ปิดเกมก่อน

```toml
[appearance]
scale = 1.0
intensity = 1.0
speed = 1.0
shape = "FLAME"
```

| ค่า | ความหมาย | ช่วง |
| --- | --- | --- |
| `scale` | ขนาดออร่าทั้งหมด | 0.5–เพดานคอนฟิค (เริ่มต้น 8) |
| `intensity` | ความสว่างและความเข้ม | 0.1–เพดานคอนฟิค (เริ่มต้น 8) |
| `speed` | ความเร็วการไหลของเปลว | 0.1–3.0 |

ออร่าของตัวเองซ่อนในมุมมองบุคคลที่หนึ่ง ส่วนออร่าของผู้เล่นอื่นยังเห็นได้ ออร่าของทุกคนซ่อนขณะล่องหน spectator ว่ายน้ำ คลาน บินด้วย elytra นอน ขี่พาหนะ และเมื่อตัวละครตาย

ไม่ต้องใช้ shader pack เพิ่ม แสงของออร่าไม่ส่องสว่างบล็อกรอบตัว และไม่ได้ทำ bloom ฟุ้งเต็มจอ ความเข้ากันได้กับ shader pack/มอดเรนเดอร์อื่นต้องทดสอบเป็นรายชุด

## เพดานขนาดและความเข้ม (0.8)

ปรับขนาดและความเข้มเกิน 2 ได้ทั้งแถบเลื่อนในหน้า O และคำสั่ง เช่น `/aura set size 4` และ `/aura set intensity 5` เพดานเริ่มต้นคือ **8** ทั้งสองค่า และตั้งเพดานได้สูงสุด **32** หน้าตัวอย่างถอยกล้องตามขนาดออร่า

เจ้าของโลก/เซิร์ฟเวอร์ตั้งค่าใน `trueaura-server.toml`:

- เล่นคนเดียว: `saves/<ชื่อโฟลเดอร์โลก>/serverconfig/trueaura-server.toml`
- เซิร์ฟเวอร์: `<level-name>/serverconfig/trueaura-server.toml`
- ค่าเริ่มต้นสำหรับโลกใหม่: วางไฟล์ใน `defaultconfigs/trueaura-server.toml`

ตัวอย่างให้ขนาดสูงสุด 10 และความเข้มสูงสุด 12:

```toml
[limits]
maxScale = 10.0
maxIntensity = 12.0
```

ออกจากโลกหรือปิดเซิร์ฟเวอร์ก่อนแก้ แล้วเปิดใหม่และเชื่อมต่อใหม่เพื่อให้ทุกคนรับเพดานเดียวกัน `maxScale` ตั้งได้ 0.5–32 และ `maxIntensity` ตั้งได้ 0.1–32 แถบเลื่อนใช้เพดานของโลก คำสั่งที่เกินเพดานจะแจ้งข้อผิดพลาด และเซิร์ฟเวอร์จำกัดค่าจากแพ็กเก็ตด้วย

ถ้าเล่นบนเซิร์ฟเวอร์ที่ **ไม่มี True Aura** จะใช้ `[limits]` ชื่อเดียวกันใน `config/trueaura-client.toml` แทน ค่าฝั่งเครื่องไม่สามารถเพิ่มเพดานที่เซิร์ฟเวอร์กำหนดไว้ได้

ขนาดออร่าหุ้มตัวขยายตามค่าที่ตั้ง ส่วนขอบเขตพื้นแตกและพาร์ติเคิลตอนเปิด–ปิดจำกัดการขยายไว้เทียบเท่าขนาด 2 เพื่อคุมจำนวนชิ้นส่วนและการอ่านบล็อกพื้น

## Shader packs (0.8)

แก้ลำดับวาดออร่าและพื้นแตกให้แสดงหลัง Oculus รวมภาพ shader พร้อมใช้เมทริกซ์กล้องจากการวาดโลก ทดสอบบน Mac ด้วย **Oculus 1.8.0 + Embeddium 0.3.31 + Forge 47.4.23** และ Epic Fight 20.14.17:

- Complementary Reimagined r5.9.3
- Complementary Unbound r5.9.3
- BSL v10.1.8

ทั้งสามชุดโหลดและแสดงออร่า พื้นกระแทก และหน้าตัวอย่างขนาด 4 / ความเข้ม 5 ได้ ดูภาพและขอบเขตการทดสอบใน `docs/verification-0.8.md`

ออร่าวาดหลังการรวมภาพ จึงไม่ได้เข้า bloom, reflection หรือการปรับแสงของ shader pack โดยตรง สีและความสว่างอาจต่างจากพาร์ติเคิลในโลก ไม่รับประกัน shader ทุกชุด ทุก preset หรือการเรียงชั้นกับน้ำ/กระจก ไม่จำเป็นต้องติดตั้ง Oculus หรือ shader pack เพื่อใช้งาน True Aura ตามปกติ

## แรงกระแทกพื้น (0.7)

เอฟเฟกต์ `trueaura:burst` และ `epicfight:ground_slam` เพิ่มแผ่นพื้นยกตัวเอียงเป็นระลอกตามแนว Meteor Slam, รอยแตกกว้าง, คลื่นพลังสองชั้น และเสียงกระแทก ตอนเปิดผลักคลื่นออกอย่างรวดเร็ว ตอนปิดดึงเข้าหาศูนย์กลางพร้อมคลื่นสะท้อนออก เศษบล็อกและฝุ่นของ Epic Fight มีจำนวน/ความเร็วเพิ่มขึ้นด้วย

เลือกได้แยกตอนเปิด/ปิดใน O → เอฟเฟกต์ หรือใช้ `/aura set open_effect trueaura:burst` และ `/aura set close_effect trueaura:burst` รุ่นไม่ติดตั้ง Epic Fight ก็ใช้แบบ burst ได้ เอฟเฟกต์ชนิดอื่นที่เลือกไว้ยังคงชนิดเดิม

แผ่นพื้นเป็นโมเดลภาพจำลองจากบล็อกที่ยืนอยู่ ไม่เปลี่ยนบล็อกจริงหรือสร้างดาเมจ แสดงสูงสุด 36 แผ่นต่อครั้งและ 192 แผ่นต่อเฟรม เลือกเฉพาะบล็อกลูกบาศก์ทึบ; พื้น slab ใช้รอยแตก/เศษดินแทน และกลางอากาศไม่มีแผ่นพื้น จังหวะยก/คืนตัวอยู่ภายในเอฟเฟกต์ 1.4–2 วินาที

## เลือกเอฟเฟกต์ตอนเปิด–ปิด

กด **O → เอฟเฟกต์ (Effects)** แล้วเลือก **ตอนเปิด / ตอนปิด** แยกกัน:

1. ค้นหาชื่อ เช่น `ground_slam`, `epicfight:` หรือ `minecraft:` รายการมาจาก particle registry ของเกมที่กำลังเปิด จึงรวมมอดที่ติดตั้งด้วย
2. เลือกรายการ ใช้ลูกศรหรือเลื่อนเมาส์เพื่อเปลี่ยนหน้า รายการ Epic Fight อยู่ก่อนพาร์ติเคิลทั่วไป
3. กด **ลองเอฟเฟกต์ (Test)** เพื่อดูเฉพาะเครื่องตัวเองก่อนบันทึก
4. ปุ่ม **…** เปิดช่องพารามิเตอร์ สำหรับชนิดที่ต้องระบุบล็อก ไอเท็ม สี หรือค่าเฉพาะของมอด ใช้เฉพาะส่วนค่าของคำสั่ง particle ไม่ใส่ `/particle` หรือพิกัดเกิด
5. กด **บันทึก** เพื่อใช้กับ R และส่งตัวเลือกให้ผู้เล่นอื่น ยกเลิก/Esc ทิ้งการแก้ค่าที่ยังไม่บันทึก

เลือก **ไม่มีเอฟเฟกต์** ได้ทั้งสองจังหวะ หรือเลือก **พลัง True Aura** เพื่อใช้คลื่นกระแทก/รอยแตกเดิม โดยไม่มีการทำลายบล็อกหรือดาเมจ ค่าเก่าจาก 0.3 ใช้เอฟเฟกต์เดิมต่อโดยอัตโนมัติ

ตัวอย่างพารามิเตอร์: `minecraft:block` → `minecraft:stone`; `minecraft:item` → `minecraft:diamond`; `minecraft:dust` → `1 0.7 0.1 1` `minecraft:shriek` รับเวลาหน่วง 0–60 tick ส่วนชนิดทั่วไปเว้นว่างได้ `minecraft:vibration` รองรับ `@self` เพื่อมุ่งเข้าหาตัวผู้เล่นที่ปล่อยเอฟเฟกต์

### Epic Fight

รองรับการเลือกพาร์ติเคิลของ **Epic Fight สำหรับ Forge 1.20.1** เมื่อมีมอดติดตั้ง ทั้ง Ground Slam, Air Burst, Neutralize, Boss Casting, Force Field, ภาพร่างติดตา และฝุ่น/ประกาย โดยส่งค่าพิเศษตาม provider ของ Epic Fight 20.14.x แทนการสุ่มค่าความเร็ว รุ่นที่ใช้ตรวจการเปิดเกมคือ **20.14.17**

- Ground Slam ต้องยืนบนพื้น และเรียกเฉพาะเอฟเฟกต์เศษพื้นของ Epic Fight ไม่เรียกท่าโจมตีหรือเปลี่ยนบล็อก
- รายการ swing trail / projectile trail แสดงแต่ปิดการเลือก เพราะต้องใช้แอนิเมชัน/กระสุนจริง; laser ยังไม่เปิดให้ใช้เพราะต้องกำหนดเป้าหมายลำแสงระยะไกล รายการ Epic Fight ที่ยังไม่มี adapter แสดงเหตุผลเช่นกัน
- เอฟเฟกต์ภาพเฉพาะของมอดที่ไม่ได้ลงทะเบียนเป็น particle ยังไม่ได้รวมใน browser นี้
- พาร์ติเคิลมอดอื่นใช้ตัวอ่านค่าของมอดนั้นเอง บางชนิดต้องมีบริบทพิเศษหรือ provider เฉพาะ จึงไม่รับประกันว่า particle ทุกชนิดของทุกมอดใช้เดี่ยว ๆ ได้ กดลองก่อนใช้งานจริง
- สี/รูปทรงของพาร์ติเคิลภายนอกขึ้นกับมอดต้นทาง ไม่ได้ถูกย้อมด้วยสีออร่าทั้งหมด
- หากผู้รับไม่มีมอดต้นทาง หรือสร้างพาร์ติเคิลนั้นไม่ได้ จะใช้เอฟเฟกต์ True Aura แทน
- จำกัดจำนวนการสร้างต่อ tick, จำกัดอายุอนุภาคที่สร้างโดยตรง และเว้นช่วง emitter ขนาดใหญ่ ทั้งนี้ provider ของมอดอาจปล่อยอนุภาคลูกของมันเอง

**เครือข่ายรุ่น 0.9 ใช้ protocol 5:** ต้องอัปเดต True Aura ทั้งเซิร์ฟเวอร์และผู้เล่นที่มีมอดเป็นรุ่น 0.9 เพื่อรองรับรูปแบบนำเข้า รุ่น 0.2–0.8 ใช้ร่วมกันไม่ได้ ถ้าต้องการเห็นพาร์ติเคิลมอดเดียวกันให้ติดตั้งมอดต้นทางด้วย

คลื่นเดิมของ True Aura ในโหมด Fabulous อาจเรียงชั้นกับกระจก/น้ำไม่สมบูรณ์เมื่ออยู่กลางอากาศ

## สำหรับผู้พัฒนา

บน macOS เปิด `rebuild-and-run.command` เพื่อ build โค้ดล่าสุดและเปิดเกมทดสอบแยกในโปรเจกต์ สคริปต์เลือก JDK 17 ที่ติดตั้งไว้หรืออยู่ใน Gradle cache

ใช้ **JDK 17** แล้วรัน:

```sh
./gradlew test build
./gradlew runClient
# เพิ่ม Epic Fight ในเกมพัฒนาเท่านั้น
./gradlew runClient -PauraEpicFight=true -Dhttps.protocols=TLSv1.2
# อีกไคลเอนต์ที่ใช้โฟลเดอร์/ชื่อแยกกัน สำหรับทดสอบหลายคน
./gradlew runClient -PauraRunDir=run-viewer -PauraUser=AuraViewer
# เซิร์ฟเวอร์พัฒนาแยก (ผู้ใช้งานต้องอ่านและยอมรับ EULA เอง)
./gradlew runServer
```

ไฟล์มอดพร้อมใช้ถูก reobfuscate โดย ForgeGradle และอยู่ใน `build/libs/` โลกพัฒนาทั้งหมดอยู่ใต้ `run/` แยกจากอินสแตนซ์ Minecraft ที่มีอยู่

ทดสอบตรรกะและรูปทรงโดยไม่ต้อง bootstrap Forge:

```sh
./gradlew -p tools test
```

หากเครือข่ายมีปัญหา TLS handshake กับ Minecraft libraries ให้ลองเพิ่ม `-Dhttps.protocols=TLSv1.2` ในคำสั่ง build โดยยังคงตรวจใบรับรอง HTTPS ตามปกติ

ซอร์สใช้ Java, Forge events และ core shader GLSL 150 มีรูปทรงและลวดลายที่สร้างเอง ไม่มีภาพ sprite ที่ดึงจาก Project Moon ดูผลทดสอบรุ่นล่าสุดใน `docs/verification-0.9.md` และการทดสอบ shader ใน `docs/verification-0.8.md` (ประวัติรุ่น 0.1 อยู่ใน `docs/verification.md`)
