# True Aura Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a cosmetic Shin-inspired aura for Minecraft Forge 1.20.1.
**Architecture:** A client-only controller handles the key and fade state; a bounded procedural mesh plus custom core shader draws the golden flames and violet base during AFTER_PARTICLES. Pure animation logic is separated from Minecraft for deterministic tests.
**Tech Stack:** Java 17, Forge 47.4.23 (available local development cache), Gradle 8.12.1, GLSL 150, JUnit 5.
**Spec:** ../specs/2026-11-09-shin-aura-design.md (approved by user 2026-11-09).

## Global Constraints
- Forge 1.20.1, local-player cosmetic only, R toggle with remapping.
- Golden/orange upward flames, pale inner streaks, violet feet; no Mang rings.
- Default off; hide own aura in first person, spectator, invisibility, swimming, fall flying, sleeping and riding.
- Smooth motion/fades, configurable scale/intensity/speed, no additional shader pack required.
- Deliver source, reobfuscated jar, Thai instructions, honest build/runtime evidence.

## Review Focus
- Disconnect/world changes must reset effect and avoid retaining player/level objects (task 1 test).
- Fast toggles and pause must not jump or advance the fade incorrectly (task 1 test, task 3 runtime).
- Hidden player states and first-person must never draw a visible shell (task 2 runtime).
- Depth occlusion, multiple camera angles, Fast/Fancy/Fabulous and resource reload must render correctly (task 3 runtime).
- Long sessions must not accumulate geometry or create nonfinite coordinates (task 2 test).

### Task 1: Buildable client lifecycle and animation state
**Files:** build.gradle, settings.gradle, gradle.properties, gradle wrapper; TrueAura.java, client/AuraClient.java, client/AuraConfig.java, client/AuraState.java; META-INF/mods.toml, pack.mcmeta, lang/en_us.json, lang/th_th.json; tests/AuraStateTest.java.
**Interfaces:** AuraState.toggle(), tick(boolean activeSession), reset(), opacity(float partialTick), enabled(), time(float partialTick). All time is tick-based, freeze by not ticking when paused.

### Task 2: Three-dimensional flame renderer
**Files:** client/AuraRenderer.java, client/AuraRenderType.java, client/AuraMesh.java; assets/trueaura/shaders/core/aura.{json,vsh,fsh}; tests/AuraMeshTest.java.
**Interfaces:** AuraMesh.emit(float time, float height, VertexSink sink); VertexSink.vertex(float x, float y, float z, float u, float v, float layer). Stateless geometry, layer distinguishes outer gold, inner streaks and violet base. Renderer consumes state opacity/time and config values.
