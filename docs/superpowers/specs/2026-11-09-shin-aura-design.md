# True Aura — แบบรุ่นแรก

สถานะ: ผู้ใช้ยืนยันให้เริ่มสร้างเมื่อ 2026-11-09

## เป้าหมายที่ผู้ใช้ระบุ

- Minecraft Java Edition, Forge 1.20.1
- ออร่าหุ้มตัวแบบ Shin ของ Project Moon
- เน้นภาพออร่า ไม่มีวงแหวน Mang
- ต้องให้ความรู้สึกเป็นพลังงานล้อมร่าง แทนเอฟเฟกต์ควันบัฟตามปกติ
- คลิปอ้างอิง: https://www.youtube.com/shorts/-qRQ3ka-3Xk — “Sancho with Shin”

## สิ่งที่เห็นในคลิป

ออร่าสีเหลืองทองไล่ไปส้มล้อมตัว มีริ้วแสงสีเหลืองอ่อนสว่างกว่าอยู่ด้านใน เปลวพลังยาวไหลขึ้นสูงเหนือศีรษะ ขอบเปลวเปลี่ยนรูปร่างและความกว้างตลอดเวลา บริเวณเท้ามีแสงม่วงอ่อนพร้อมริ้วสั้นที่ยกตัวขึ้น ตัวละครยังมองเห็นผ่านช่องว่างและส่วนโปร่งแสงของออร่าได้

ทรงรวมเป็นเปลวพลังหุ้มทั้งร่าง มีพื้นที่ระหว่างผิวตัวละครกับออร่า ไม่ควรตีความเป็นเพียงเส้นขอบที่แนบตามแขนขา

## ขอบเขตรุ่นแรกที่ผู้ช่วยเสนอ

ข้อกำหนดในส่วนนี้เป็นค่าเริ่มต้นที่ผู้ช่วยเลือก ยังไม่ใช่ความต้องการที่ผู้ใช้ยืนยัน

1. มอดเอฟเฟกต์ฝั่งไคลเอนต์สำหรับตัวผู้เล่นเอง ดูออร่ารอบตัวได้ในมุมมองบุคคลที่สาม เล่นได้ทั้งโลกเดี่ยวและเมื่อเข้าร่วมเซิร์ฟเวอร์ แต่ยังไม่ส่งสถานะออร่าให้ผู้เล่นอื่นเห็น
2. ปุ่ม `R` เปิด–ปิดออร่า เปลี่ยนปุ่มได้ผ่าน Controls ของเกม เปิดเกมครั้งใหม่เริ่มที่ปิด
3. ออร่าหลักสีทองอมส้ม มีริ้วสว่างด้านในและชั้นม่วงอ่อนใกล้เท้า ยึดสัดส่วนและจังหวะจากคลิปเป็นเป้าหมายทางภาพ
4. รูปร่างมีความลึก มองรอบตัวได้ ไม่เป็นภาพแผ่นเดียวที่เห็นผลเฉพาะมุมกล้องหนึ่ง
5. ฐานออร่าตามตำแหน่งเท้าอย่างราบรื่นระหว่างยืน เดิน วิ่ง กระโดด และย่อตัว เปลวด้านบนแกว่งอย่างต่อเนื่อง ออร่าจางเข้า–ออกเมื่อเปิดหรือปิด
6. ในมุมมองบุคคลที่หนึ่งซ่อนออร่าของตนเองเพื่อให้มองทางได้ชัด ซ่อนระหว่าง spectator และเมื่อตัวละครล่องหน ส่วนท่าว่ายน้ำ บินด้วย elytra นอน และขี่พาหนะจะซ่อนเอฟเฟกต์ในรุ่นแรก
7. ไม่มีการเพิ่มดาเมจ บัฟ หรือระบบต่อสู้ รุ่นแรกใช้ทดสอบความใกล้เคียงด้านภาพ
8. ปรับขนาด ความเข้ม และความเร็วของออร่าได้ในไฟล์ config โดยไม่ต้องแก้โค้ด ยังไม่มีหน้าจอตั้งค่าเฉพาะ
9. ใช้ภาพและรูปทรงที่สร้างขึ้นใหม่โดยอ้างอิงลักษณะของคลิป ไม่ดึง sprite จากเกม

## แนวทางสำหรับผู้พัฒนา

สร้างชั้นเรนเดอร์พลังงานโปร่งแสงซ้อนกันรอบผู้เล่น ใช้ผิวหรือแถบเปลวที่มีรูปทรงและลวดลายเคลื่อนไหวต่อเนื่อง ให้ขอบสว่างและเนื้อด้านในบางกว่า เลือกเทคนิคจริงหลังตรวจ API ของ Forge 1.20.1 และความสามารถของสภาพแวดล้อม

เป้าหมายพื้นฐานต้องทำงานโดยไม่ต้องติดตั้ง shader pack เพิ่ม ความสว่างของสีเป็นส่วนหนึ่งของเอฟเฟกต์ แต่แสงฟุ้งแบบ bloom และแสงที่ส่องบล็อกรอบตัวไม่ได้อยู่ในขอบเขตรุ่นแรก ไม่รับรองการทำงานร่วมกับ shader pack หรือมอดเรนเดอร์อื่นจนกว่าจะได้ทดสอบ

ให้ผู้พัฒนาเลือก Forge build ที่เหมาะกับ 1.20.1, โครงสร้างโค้ด, วิธีทำพื้นผิว, จำนวนชั้น, ความละเอียด และวิธีเรนเดอร์ ปรับค่าจนภาพใกล้ต้นแบบโดยจำกัดจำนวนองค์ประกอบต่อเฟรม ไม่มีการสะสมเอฟเฟกต์ตามเวลา

## เกณฑ์ตรวจรับ

- สร้างไฟล์ `.jar` สำหรับ Forge 1.20.1 ได้ พร้อมวิธีติดตั้งและใช้งานภาษาไทย
- เปิดเกมและเข้าโลกทดสอบได้ ปุ่มเปิด–ปิดและการเปลี่ยนปุ่มทำงาน
- มุมมองบุคคลที่สามเห็นเปลวสีทองอมส้มยกขึ้นรอบร่าง มีชั้นม่วงที่ฐาน และเห็นตัวละครภายใน
- หมุนกล้องรอบตัวแล้วออร่ายังคงหุ้มร่าง ผนังบังเอฟเฟกต์ได้ตามปกติ
- ระหว่างเคลื่อนที่และย่อตัว ออร่าตามผู้เล่นอย่างราบรื่น ไม่มีภาพค้างหรือปล่อยองค์ประกอบสะสมในโลก
- การเปิด–ปิด มุมมองบุคคลที่หนึ่ง และท่าที่กำหนดให้ซ่อน ทำงานตามขอบเขต
- ตรวจภาพจริงในเกมเทียบกับคลิปก่อนอ้างว่าใกล้เคียง หากรันเกมหรือทดสอบภาพไม่ได้ ต้องรายงานแยกจากผลการ build อย่างชัดเจน

## สิ่งที่จะส่งมอบหลังยืนยันแบบ

ซอร์สโปรเจกต์ True Aura, ไฟล์มอดที่ build แล้ว, วิธีติดตั้งและปรับค่า และผลตรวจสอบที่ทำได้จริง รุ่นแรกมีไว้ให้ผู้ใช้ลองภาพในเกมและชี้จุดปรับรูปร่างต่อไป
